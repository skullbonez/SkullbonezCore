# Official SkullbonezCore logo

![Official SkullbonezCore logo](skullbonez-logo.png)

- [SVG](skullbonez-logo.svg): scalable vector artwork for documentation and design.
- [PNG](skullbonez-logo.png): the original approved 256 × 256 raster, preserved unchanged.

Both versions use the approved pale skull, dark eye/nose details, and black square background. Keep the square aspect ratio and original colors. The SVG recreates the raster with editable geometric shapes; it contains no embedded image or font dependencies.

These are the official logo files. The `split-state-*` assets are earlier artwork, not the canonical logo. Existing application icons remain separate runtime assets.
