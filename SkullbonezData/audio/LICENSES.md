# Audio Asset Licenses

Runtime impact sounds in `SkullbonezData/audio/impacts/` are generic contact
thuds sourced from an OpenGameArt CC0 sound effect pack by `rubberduck`.

## Source Pack

- Source page: https://opengameart.org/content/100-cc0-sfx-2
- Author: rubberduck
- License: Creative Commons CC0
- Download date: 2026-07-02
- Downloaded archive: `sfx_100_v2.zip`
- Original page notes: includes air, door, footstep, glass, hit, item, metal,
  stone, switch, thunder, water, and wood sounds.

## Runtime Files

| Runtime file | Original file |
