Color Language

Replace cyan glow with neutral greys, off-white type, and one quiet accent per mode. Use accents for selected state and filled slider values only.

Shape System

Use 8px outer corners, 6px controls, and pill switches. Avoid hard neon outlines; prefer 1px borders and soft shadows for depth.

Implementation Fit

The mockups map onto existing draw calls: window frame, title buttons, tabs, combo boxes, toggles, sliders, and footer stats can be restyled without changing app flow.
